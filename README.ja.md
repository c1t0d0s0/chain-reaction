**ピタゴラ・チェインリアクション (Chain Reaction Studio)** は、NHK「ピタゴラスイッチ」やルーブ・ゴールドバーグ・マシン（からくり装置）の世界観をブラウザ上で自由に再現・実験できる、2D物理シミュレーションサンドボックスWebアプリケーションです。

横視点の重力空間上で、赤いビー玉、木の板、ドミノ、バネ、シーソー、紙コップ、トイレットペーパーの芯、輪ゴム、糸振り子、扇風機、磁石、回転水車、音階ベル、すり鉢ロート、てこカタパルト、滑車バケツ、蛇口、そして床に溜まる水など、多彩な日常の道具を自由に配置・連結して、自分だけのワクワクする連鎖装置を組み立てることができます。

## ✨ 主な機能と特徴

### 1. 🛠️ 19種類以上の多彩な物理ギミックと道具
細部まで調整された物理プロパティ（密度、摩擦係数、反発係数、空気抵抗、流体力学）を持つパーツ群：

| 分類 | アイテム | 特徴と挙動 |
| :--- | :--- | :--- |
| **ボール・発射** | 🔵 **ビー玉** | ガラス玉特有の美しい弾みと回転、速度に応じたリアルな転がり摩擦音を再現。 |
| | 🏁 **スタートゲート** | 再生開始と同時にストッパーが外れ、ビー玉を滑らかに転がし始める発射台。 |
| | 🚩 **ゴールフラッグ** | ビー玉が飛び込むとピンポン♪のファンファーレとともに華やかな紙吹雪が舞い散る目標地点。 |
| **基礎パーツ** | 🪵 **木の板** | スロープや足場、架橋など自由に傾けて配置できる万能の木製レール。 |
| | 🧱 **重いレンガ** | シーソーの押し下げや滑車バケツの重りとして活躍する高密度セラミック素材（密度0.012、質量約31.1）。水にも沈降。 |
| | 🀄 **ドミノ** | 倒れる重力ポテンシャルが次のドミノを力強く押し倒す黄金比率（幅11×高さ54px）。小気味よい連鎖音。 |
| **推進・跳躍** | 🌀 **反発バネ** | ボールや物体を勢いよく跳ね返す高反発バウンサー（反発係数1.65）。金属的なバネ伸縮アニメーションと「ボヨヨン！」音。 |
| | ⚖️ **シーソー** | 支点回転ピン（可動域±23°リミッター・静止摩擦ラッチ・ダンピング付き）。重さの不均衡でカタンと傾く機構。 |
| | 🥄 **てこカタパルト** | アンビル側に重いものが落下衝突すると、長いアーム側のスプーンに乗ったボールを放物線状に高く打ち上げる跳ね上げ台。 |
| | ➰ **輪ゴム** | しなやかなトランポリン弾性でボールを斜め上方へ勢いよく跳ね返すゴムバンド。 |
| **受け皿・トンネル**| 🥤 **紙コップ** | 超軽量（密度0.0008）の紙製コップ。ボールが入るとコロンと転がり、水が入るとズッシリ重くなり水面にプカプカ浮遊。 |
| | 🧻 **ペーパー芯** | ボールがスルリとくぐり抜ける低摩擦の中空トンネル。滑らかな誘導ガイド付き。 |
| | 🌀 **すり鉢ロート** | 飛び込んだボールが遠心力で何周も渦を巻いて旋回減速し、中央の穴から真下へ落下するディレイ（時間差）ギミック。 |
| | 🏗️ **滑車バケツ** | ボビンを通した糸で両端のバケツが連動する定滑車。ボールやレンガの重み、注水された水の重みで片方が下がり反対側が上昇。満杯時は水があふれ出す機構。 |
| **環境・音響** | 🌪️ **扇風機** | 距離減衰と円錐状拡散を持つ指向性エアフォースを噴射。軽い物体を吹き飛ばし、水車を回転。 |
| | 🧲 **磁石** | クランプ付き逆自乗則磁場（引き寄せ／反発の切替可能）。金属球やドミノを遠隔で引き寄せ・反発。 |
| | 🔔 **音階ベル** | ボールが当たると澄んだベル音が響く卓上ベル。ド・レ・ミ・ファ・ソ・ラ・シ・高ドの8音階から音程を自由に設定可能。 |
| | ⚙️ **回転水車** | 中央の軸を中心に滑らかに回転するパドル車。ボールの衝突、扇風機の風、蛇口の水流を受けて勢いよく回転。 |
| **流体・水** | 🚰 **水道の蛇口** | レトロな蛇口から光沢のある本物の物理水滴粒子（`water_drop`）がリアルタイムにポタポタと連続滴下。 |
| | 🌊 **床水蓄積＆プール** | 蛇口から床に落ちた水が時間とともにどんどん溜まり水位が上昇。水面波紋、浮力（アルキメデス原理）、水中粘性抵抗、壁の水位計、ワンクリック排水を完備。 |

### 2. 🌊 本格的な流体シミュレーション＆床水蓄積システム
- **水滴の吸収と水位上昇**: 蛇口から落ちた水や、コップ・バケツからあふれ出た水滴が床に到達すると、床全体に水が広がり水位が徐々に上昇（約8秒で約18mmの水深プールに成長）。
- **水面波紋と表面張力（メニスカス）**: 着水地点から同心円状に広がる物理波紋と、2重サイン波による有機的な水面の揺らぎ。左右の壁際では表面張力によって水面がキュッと持ち上がるリアルなメニスカス曲線を再現。
- **浮力と水中粘性抵抗**: 水に浸かった物体には浸水体積と素材密度に応じた上向き浮力と水流抵抗が働き、紙コップは水面にプカプカと浮かび、ビー玉やレンガは水中を減速しながら床底へと沈降します。
- **壁に刻まれたミリメートル水位計**: 左壁の木柱に刻印されたスケール定規（20mmごとの目盛り、現在水位を示す水色三角マーカーと「18mm」等のリアルタイム深度表示）が実験室の雰囲気を演出。
- **ワンクリック排水機能**: ツールバーの **「💧 排水」** ボタンから、配置したオブジェクトを崩すことなく、いつでもワンタップで床の水だけをサッと乾かすことができます。

### 3. 🎵 プロシージャルWeb Audio音響エンジン
外部の音声ファイル読み込みは一切不要。すべての効果音を **Web Audio API** でリアルタイムに波形合成：
- **ビー玉の転がり音**: ボールの移動速度に追従して音程と音量が動的に変化する連続摩擦音。
- **材質別の衝突音**: 木材、金属、ガラス玉、レンガ、ドミノ、バネ、着水音など、それぞれの硬度と質量を反映したリアルな打撃音。
- **調律された楽器音**: 8音階の澄んだ共鳴ベルチャイム。
- **環境音**: 扇風機のモーター回転音、蛇口の金属スナップ音、リズミカルな滴下音。

### 4. 📱 タブレット完全対応＆サクサク装置制作UI
PCマウス・トラックパッドはもちろん、iPadなどのマルチタッチ操作に完全対応：
- **ピンチイン・ピンチアウト**: 2本指の中間点を中心とした滑らかな拡大・縮小（0.35x 〜 3.0x）。
- **2本指パン移動**: 画面全体を直感的にスワイプスクロール。
- **タッチ操作しやすい拡大ハンドル**: 指先でも確実に掴める回転ハンドルと角度バッジ表示。
- **クイックアクションバー**: オブジェクト選択時、すぐ上に片手操作バーが出現（複製、±15°回転、左右反転、削除）。
- **スマート・ドッキング・インスペクター**: 選択オブジェクトの画面位置（右/左）に応じて、自動的に反対側の画面端へオーバーレイドッキング。オブジェクトがパネルで隠れたり画面が歪むストレスを完全解消。
- **スナップ＆連続スタンプ配置**:
  - 🧲 **15°角度＆20pxグリッドスナップ**: 傾きや位置のズレを瞬時に吸着整列。
  - 📌 **連続スタンプ配置モード**: パレットで選んだ道具をキャンバス上でタップするだけで連続配置。

### 5. 💾 4つのデモコース＆JSON保存・読み込み
- **初期搭載デモコース**:
  1. **基本の坂道とドミノ連鎖**: スロープ、ドミノ、シーソー、ベル、ゴールへの到達。
  2. **バネと芯の空中ジャンプ**: 高反発バネ、芯トンネルの通過、カタパルトの空中跳躍。
  3. **風と水と磁石のからくり大実験**: 扇風機の風力、磁石の吸着、水力によるシーソー傾斜。
  4. **ピタゴラからくり大実験**: 回転水車、メロディベル（ド・ミ・ソ♪）、すり鉢ロートの渦巻き、跳ね上げカタパルト、滑車エレベーターの壮大な連鎖。
- **コースの保存と読み込み**: 作成した装置をJSON形式でダウンロード保存し、いつでも読み込み可能。画面の表示倍率や視点位置も正確に復元されます。

## 🕹️ 操作方法とショートカット一覧

### マウス＆タッチ操作
- **左クリック / タップ**: オブジェクトの選択、道具の配置、ドラッグ移動。
- **右クリックドラッグ / Space + ドラッグ / 2本指ドラッグ**: 画面（カメラ）のスクロール移動。
- **マウスホイール / ピンチ**: 拡大・縮小（ズーム）。
- **外周回転ハンドル**: ドラッグして角度を自由回転（スナップON時は15°刻み）。

### キーボードショートカット
| キー | 動作 |
| :--- | :--- |
| `Space` | シミュレーションの再生／一時停止（または編集モードから再生） |
| `R` | コースを初期状態にやり直す（リセット） |
| `Backspace` / `Delete` | 選択中のオブジェクトを削除 |
| `G` | グリッド表示のON / OFF切替 |
| `S` | 15°角度＆20pxグリッドスナップのON / OFF切替 |
| `C` | 連続スタンプ配置モードのON / OFF切替 |
| `F` | ボール自動追従カメラのON / OFF切替 |
| `+` / `-` | 画面の拡大 / 縮小 |
| `0` | 画面の倍率と表示位置を100%にリセット |

## 🚀 開発環境のセットアップ

### 必要要件
- [Node.js](https://nodejs.org/) (v18.0 以上推奨)
- npm または pnpm または yarn

### インストールと起動
```bash
# 1. リポジトリをクローン
git clone https://github.com/your-username/chain-reaction.git
cd chain-reaction

# 2. 依存パッケージをインストール
npm install

# 3. 開発用ローカルサーバーを起動
npm run dev
```
ブラウザで `http://localhost:5173` を開いて遊ぶことができます。

### プロダクションビルド
```bash
# TypeScript型チェックおよびViteビルド
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```
